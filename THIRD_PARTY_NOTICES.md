Direct dependencies include Avalonia/Avalonia.Desktop 12 and SukiUI (MIT). SukiUI brings Avalonia.Themes.Simple, Avalonia.Controls.ColorPicker, Avalonia.Controls.DataGrid and System.Linq.Dynamic.Core; its bundled fonts and icon geometries keep their upstream licenses. The application uses operating-system WKWebView/AppKit on macOS and the separately built Windows WebKit Port on Windows. Documentation uses VitePress/Vue and development checks use Node tooling. Optional presentation sheets use the locked Pillow runtime dependency; optional PDF-mask checks use a separately installed Poppler utility. These tools and runtimes are not vendored here.

Windows WebKit is the sole Windows engine. Its Avalonia integration builds pinned upstream source with a maintained host API patch; standalone comparison probes download a URL-pinned official CI runtime into ignored local directories. WebKit, JavaScriptCore and third-party runtime libraries retain their upstream licenses; the root MIT License does not relicense them. The Windows release workflow bundles the independently versioned host runtime selected by metadata; the official testing runtime is never substituted. Runtime packages retain available upstream/vcpkg license texts, exact source revision and maintained build inputs/patches. Retain upstream notices and review the complete binary package's license/source obligations before redistribution. The small C ABI declarations reference the exact upstream revision recorded in the runtime lock.

`config/device-profiles.json` includes transformed screen paths and exterior geometry derived from artwork in a locally installed Apple Device Hub simulator profile. `config/safari-scenes.json` contains measured simulator Safari geometry and provenance hashes. These describe a simulator appearance; they do not establish actual hardware dimensions. Original Apple PDFs, binaries, screenshots, videos and extracted source bundles are excluded from Git.

No independent redistribution license for Apple's source artwork has been established in this project. Simulator-derived path data is identified here separately from first-party code and is not relicensed by the root MIT License. Review that provenance and the relevant rights before distributing derived artwork or packaged releases. This repository preparation does not claim that review has occurred.

`docs/shared/safari-reference/` contains reviewed, cropped WebP derivatives of Device Hub windows showing a first-party local fixture and Apple's simulator exterior/Safari UI. The manifest records original hashes, crop coordinates, encoding and observed geometry; original PNGs, native records and personal device metadata remain excluded. These derivatives document observed behavior and do not gain an MIT redistribution license for Apple UI/artwork. The redistribution uncertainty above still applies.

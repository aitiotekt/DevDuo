# 变更日志

<!-- Unreleased -->

## 0.1.0-beta.1

首个 beta 候选版本，尚未发布。应用与 Windows WebKit 引擎分别管理版本和发布门禁。

- 初始 Windows WebKit 候选版本与应用对齐为 `0.1.0-beta.1`。源码缓存初始化中断后可继续构建，复用已下载 Git 对象并完整保留残留文件；未知缓存状态仍拒绝覆盖，并以 Windows PowerShell 测试恢复边界。

- 完成 Windows 到 macOS 的集成审查，记录限定原生结果与首次发布前置条件，并同步候选版本。修复 macOS Inspector 异步停靠挤小被测视口的问题，由原生浏览器处理焦点内 Inspector 快捷键；CI 执行 AppKit 断言，交接文档保留明确的平台缺口。
- 为 macOS 工具 WKWebView 提供按实际尺寸布局的原生容器，使离线 Chrome DevTools 前端正确绘制合成控件，并在真实窗口验证 DOM/样式和 Console 求值。
- macOS 分数 Fit 使用精确逻辑视口尺寸，不再将浮点 bounds 误差传给 WebKit；为实测丢失一像素的问题添加回归测试。
- Windows 托管代码交叉编译不再要求本地生成 C++ compositor，原生 Windows 打包要求不变。既有 uv 环境可使用兼容的 mise Python 补丁版本。

### 视口工作台

- 未配置网站时从离线欢迎页启动，提供主页导航及元数据管理的仓库/文档链接。颜色演示和依赖接收器的标定入口移入开发者工具。活动示意标签显示当前文档真实标题，使用原生宽度测量尾部省略，并保留完整 Windows 无障碍文本。
- 原生固定容器和 dialog 背景颜色可延伸到遮挡 inset，不改变真实视口或滚动几何。Windows 通过版本化的异步四边 API 查询 WebCore；macOS 在能力可用时启用系统延伸实现，并单独记录原生待验收范围。
- Avalonia 桌面视口工作台：macOS 使用系统 WKWebView，Windows 使用固定的源码构建 WebKit 后端。提供 Safari 与沉浸容器、独立的屏幕与外壳几何、八个机身/折叠映射，以及 24 个初始/滚动 Safari 状态，含展开单标签与多标签变体。展开多标签外壳固定为两个示意标签，共用派生呈现框；原始采集和视口预留保持原样。选中标签的可见边界和标题居中遵循实测容器。未知硬件尺寸保持 null。
- 机身/画布坐标与屏幕/机身坐标分开。Closed 180° 以倒置纵向机身呈现，并保留实测横屏布局。Windows 使用实时原生旋转、变换后的屏幕遮罩和指针逆变换；macOS 使用 NSView 坐标变换。
- 宿主基于 Avalonia 12 和 SukiUI：真实地址栏绑定原生导航，并提供分组设置、状态栏、明暗主题、快捷键、无障碍标签和宿主设置持久化。持久化范围不含机身角度。标定标签只加在本地接收器页面上，并保留 query 与 fragment。呈现变化保留已加载文档，有意的模式切换仍会重建视图，夹具翻译保持滚动位置。延迟到达的地址文本与用户编辑区分开，原生导航和本地化夹具标签会继续更新地址栏。
- 英文与简体中文界面可持久化，原生控件和自有示例页即时更新，并带有资源与场景不变性测试。
- 两种容器都在首次请求前通过原生 WebKit 设置实测 iPhone Safari User-Agent，使 HTTP 身份与页面可见身份一致。冻结的 OS 字段、实测桌面引擎与 platform，以及独立的开发工具前端身份分别保留。
- macOS 恢复文档末端的原生 canvas 底色，实色 fixed 底栏做被动颜色延伸，并在布局完成后摆放原生预览。

### Windows WebKit

- 用继承的父进程能力和 UI 主动推送、初始化前确认的连接所属 Web/GPU/Network 能力，替代接收端重复获取进程句柄。查询通过线程安全引用保活，不复制进程句柄。保留普通句柄转移的所有权规则，限制继承范围，拒绝过期握手，并新增 HTTP/内联冷导航、真实源像素计时、Network 崩溃恢复及原生生命周期检查。
- 在隔离的 Canvas 读回等待前完成 GPU 初始化，bootstrap 后使用当前配置构造 Network 连接参数，并在验证已排队的文档消息时保留渲染器当前观测。
- Windows 使用 Avalonia Windows WebKit 后端：非测试宿主 API v2、锁定的便携源码构建、明确的 vcpkg 解释器归属、运行时完整性校验，以及按编译器源码校验和核对的原生验收证据。启动时发现已校验的源码运行时。后端保持四边内容延伸，以及视口、fixed 和滚动几何；逻辑场景比例与 backing 比例彼此独立。宿主窗口不透明，以便原生子窗口合成，实时正文经原生工具栏 alpha 透出。每个最终测量框只提交一次。文档末端的滚动夹紧保持 compact 工具栏收起。被动原生颜色层只填补实际文档末端之外的区域；实色通栏 footer 是单独的近似。
- Windows GDI 外壳改为实时 WebKit 表面的 DirectComposition 模糊，以及 Direct2D/DirectWrite 绘制。圆角透明、材质和字形透明度彼此独立。外壳包含分层玻璃、被动的摄像头/Wi-Fi/时钟示意、独立的 Safari 外壳动作，以及 DirectWrite 紧凑文字测量。版本化原生 RGB 边缘采样带有主题优先、防抖和过期代次拒绝，采样结果驱动外壳配色。桌面滚动条占位已去除。承载窗口和 Avalonia holder 都按屏幕路径裁剪。遮蔽 inset 下的非合成正文照常绘制，布局几何保持不变。
- 分数 Fit 对齐原生硬裁剪的像素取整，软件绘制在 GDI 上传前铺到明确的页面背景上。backing store 平移落不到整数设备像素时，改为绘制原生滚动失效。物理窗口尺寸独立于逻辑视口更新。缩放时停用旧像素复制；尺寸或祖先裁剪变化会使实时表面失效重绘。遮蔽 inset 变化，包括 compact 工具栏收起后露出的条带，会请求完整场景重绘。
- 加速帧经 WebKit 原生离屏 backing store 送出，并带上提交时的逻辑尺寸与比例。记录绘制计数，并缓存未变化的宿主文本测量。Avalonia 掌管 Windows 消息泵时，WTF 计时器截止任务照常执行。计时器修复与后续首次导航 IPC 修复分别处理不同原因。源帧计时与最终桌面 FPS 分开测量，最终桌面合成仍须单独做可视验收。
- Windows 网站数据跨启动保留。旋转保留文档、表单和历史。提供导航计时；DOM 观测尚未返回时，早期页面绘制保持可见。原生宿主凭应用清单启动，DPI、预览 zoom 和外壳字体缩放已经修正。
- Windows 在 200% DPI 下具备 24 状态原生视口基准。普通页面回归覆盖 152 组，包括 painting v2、未经修改的静态边界检查，以及真实显示器上 100%、150%、200% DPI 检查。这些检查保留文档、视口、fixed 与 sticky 元素和滚动位置。更广泛的原生输入、DPI 和外观验收仍待完成。

### Safari 外壳与参考

- 按新的 Device Hub 调研矫正 Windows Safari 主文档纵向指示器：静止时隐藏，确认原生滚动后及到达末端时短暂显示，再在整个屏幕外缘淡出。保留页面 CSS 隐藏规则、零沟槽和视口几何；时长和厚度明确属于近似参数。
- Open 内容方向遵循原始 Safari 画布。原生外观与页面背景、meta 提示分开。外壳过渡跟随原生滚动意图。合成 v3 按角色使用玻璃材质，字形对比度独立。
- 48 张经过审查的 Device Hub Safari 画布参考、四张 WebP 矩阵总览、一张颜色触发对照，以及明确的配色、滚动和标签触发记录。便携校验、导出和原生滑动工具与采集、提取、对比、验证工具放在一起。私有证据留在 Git 之外。

### 开发工具

- 开发工具移到设置侧栏最顶部，每次启动默认折叠，展开状态只保留在当前会话。颜色演示、标定快捷入口及服务提示放到检查、CDP 和代理控件之后；材质和诊断展开偏好继续保存。
- 开发工具分组：可分离的原生 Web Inspector，带侧栏开关、F12 和 Ctrl+Shift+I；显式开启的原生远程检查；token 保护的页面 CDP；离线 chii Chrome DevTools 前端。固定版本的 chobitsu 经原生消息桥提供有边界的 JavaScript 协议子集。目标导航时重新连接前端，页面保持加载。服务以关闭状态启动，停止时释放监听。原生页面代理设置会持久化，并写明平台限制。这一层的 macOS 原生验收仍待完成。

### 仓库与发布

- 新增融合 Duo 与开发者符号的应用图标，提供 Windows ICO/窗口资源，以及 macOS Icon Composer 源文件、Xcode 编译的 Assets.car 和带安全边距的 ICNS。macOS 两种格式在签名前入包，发布审计核对已保存资源哈希。

- 生产 WebKit 补丁与构建工具迁至 `native/webkit/windows`，应用源码和运行时网页资源按职责分组，跨平台核心测试与本地化测试拆分。保留历史运行时输入哈希和来源记录，新增双语平台对齐/macOS 验收交接文档。
- 跨平台 CI 在 Ubuntu 执行一次，原生应用和测试工具分别编译，仅完整纯文档 PR 可跳过原生编译。限制任务时长和产物保留期，串行发布保留多个等待版本，在昂贵打包前拒绝已被其他提交使用的版本。兼容原生 PowerShell JSON 的 UTF-8 BOM，同时保留原始清单字节。

- `just` 驱动仓库流程，mise 选择运行时，pnpm 与 uv 各自维护本生态和冻结锁。原先 20 个工具归并为仍在维护的 Python 与 Swift 工具，过时包装已移除，仅供历史复现的归档已写明用法。macOS WKWebView 桥接位于 `src/DevDuo/macos`，Device Hub XCUITest 探针位于 `scripts/DeviceHubUITests`。
- 中英文文档按编号整理，VitePress 文档站要求真实相对符号链接和源文件配对。15 篇技术指南合并为 8 篇，两种语言都有一份日常开发指南和按任务组织的导航。
- `devduo-metadata.toml` 是发布配置来源，版本可同步设置、递增并检查漂移。Checks 平台矩阵跟随该元数据，尚未验证的 Linux 检查和发布保持关闭。macOS 与 Windows 发布打包有门禁，macOS 发行包签名并公证，产物带完整性与来源校验，Pages 只从 `main` 部署。另有经过校验的本地 Windows Release 打包命令。发布审计覆盖设备与网络标识、私网地址、内网域名、MAC 地址、路径和只读暂存文本。字面的局域网测试地址改为受控夹具。
- Windows WebKit 运行时发布为手动、由元数据管理，在持久自托管 runner 上构建，包含精确下载与打包、归档和文件完整性校验、保留的原生构建缓存，以及应用清单中的引擎 pin。首次发布准备包括手动演练、已发布引擎预检、经校验且可续传的草稿、定界归档哈希、避开 token 过期的原生构建时限，以及 Pages 部署前的发布审计。首次服务器发布尚未执行。本节记录开发工作，发行版本身尚未发布。详见[验证记录](003-CALIBRATION-WORKFLOW.md)和[路线图](100-ROADMAP.md)。

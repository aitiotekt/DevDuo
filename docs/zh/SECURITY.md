# 安全

DevDuo 是实验性本地开发工具，目前开发版本未建立安全支持期限或生产加固承诺。

测量接收器是未认证的 HTTP 开发服务，应保持默认 loopback 绑定。显式绑定可达网卡会将记录端点暴露给所在网络；不要作为公共服务，也不要提交密钥。端点接收测量 JSON，不执行远程 shell 命令。桌面原生浏览器会访问用户选择的内容，并保留真实引擎行为。

SDK 和浏览器应通过正常渠道更新。Windows WebKit 固定源码版本，维护者需有意同步更新修订、补丁和哈希，重新构建并执行原生验收。项目依赖由锁文件解析。构建和公开文件检查不能证明任意页面或第三方运行时安全。

敏感漏洞报告优先使用仓库已启用的私密漏洞报告功能；如果不可用，可先公开询问私密联系方式，不附利用细节、凭证或私人浏览记录。普通非敏感问题应包含通用平台/运行时信息及可复现步骤，并移除模拟器标识与个人路径。

另见[隐私](PRIVACY.md)、[贡献指南](CONTRIBUTING.md)与[第三方说明](THIRD_PARTY_NOTICES.md)。

远程检查须显式启用，每次启动均关闭。页面 CDP 允许 JavaScript 求值和访问网站数据，所有 HTTP/前端/发现/WebSocket 路由每次启动使用新的随机 token，默认只绑定回环。token 属于访问凭据，服务不提供 TLS 或多用户授权；选择局域网会向所在网络开放。Windows 原生远程 Inspector 是独立、无认证的 WebKit TCP 协议，不受 CDP token 保护；macOS 原生检查遵循 Safari 系统发现规则。使用完应停止监听，不向公网开放这些开发端点。代理端点不接受凭据，DevDuo 不实现代理认证，也不关闭引擎 TLS 校验。

# 隐私

DevDuo 的标定接收器及诊断输出写入本地文件，目前没有独立的分析服务或托管遥测收集器。用户选择远程 URL 时，仍会通过系统浏览器引擎连接该网站；本工具不提供匿名浏览。

测量页记录视口/屏幕指标、safe area、所选标签、环境及当前 URL；接收器增加时间戳、不透明记录 ID 和连接源地址。桌面观察器包含滚动/视口、标题、主机名和页面衍生颜色。原生采集还可能记录模拟器标识、浏览标题/URL、截图、视频、辅助功能树、工具输出路径及源哈希。

原始记录应放在被忽略的 `captures/`、`measurements/` 或 `.local/`。`temp/` 下生成的诊断输出也可能包含私人元数据。Windows WebKit 将 localStorage、IndexedDB、持久 Cookie 和缓存等网站数据保存在当前用户本地应用数据的 `DevDuo/WebKit` 目录。`DEVDUO_WEBKIT_PROFILE` 可指定绝对 profile 路径，也用于隔离测试数据。旧浏览器引擎的 profile 不会被迁移或自动删除。Inspector 的 Network、Storage、Console 可显示网站数据；分享导出的诊断或截图前应检查内容。`DEVDUO_OUTPUT_DIR` 可改变桌面状态输出位置。宿主语言、设置及最近打开的 http/https 地址保存在 `DevDuo/preferences.json`；**重置设置**不会清除该地址或网站数据，删除偏好文件只会移除宿主偏好。删除证据或浏览器 profile 是用户主动的本地操作，项目尚无自动保留期限策略。

公开配置保留部分模拟器测量值、源文件相对引用和哈希，原始会话不进入 Git。分享前必须检查元数据及图片，发布经过脱敏的衍生物，同时保持原件字节不变。不得公开密钥、个人主机或账户名、局域网设备或 VLAN 编号、实际 IP/MAC 地址、内网域名、模拟器标识、私人页面内容或私有绝对路径。回环地址、保留的文档示例地址以及应用自有的 `devduo.local` 夹具域名是受控测试数据，不代表个人网络清单。

`just public-audit` 检查已跟踪及可添加的工作区文件，包括文档和隐藏的工作流文件，并验证已审查参考图片的尺寸与元数据。规则覆盖私网范围、有主机语境的字面 IP、设备名称和编号、内网域名、MAC 地址及私有路径，错误信息不回显命中的正文。`just public-audit-index` 额外检查暂存文本，避免将工作区修正版误当成仍留在暂存区的旧版本。两个命令均只读，不自动暂存修复；提交前应纳入已审查修改并重新检查暂存快照。文本规则不能证明任意图片或 Git 历史绝无个人信息，忽略的原始证据仍应保持私有且原样保留。

另见[参考数据](002-MEASUREMENT-CONTRACT.md)和[安全](SECURITY.md)。

可选远程调试向连接者开放页面数据，并允许检查页面及执行 JavaScript。CDP 发现记录包含页面标题和 URL，Console、DOM、Storage 及观测到的网络数据可能包含凭据或私人内容。CDP 基础地址、发现接口与 socket 地址固定且不含凭据。明确填写的请求头令牌以明文保存在本机偏好文件中，在设置字段中遮蔽显示，不进入普通宿主序列化或复制地址；agent 客户端通过 Authorization 请求头发送。令牌在服务/应用重启后保留，监听启用状态仍不保存。内部前端 URL 可包含另一份临时 socket 访问能力，每次启动服务均改变，分享截图、日志或报告前须移除。默认仅绑定回环；显式选择局域网会通过活动 IPv4 接口开放服务。Windows 原生远程检查使用独立、无认证的 WebKit TCP 协议；macOS 使用系统 Safari 发现，该开关不会创建 CDP 监听。两项远程服务都不会根据保存的偏好自动启动。关闭容器或服务会释放监听和连接。当前文档的 chobitsu hook 无法安全撤销；关闭时静音消息桥并移除后续注入，只有用户主动刷新目标页才会清除这些 hook。

自定义页面代理按原生引擎代理规则接收网站流量。DevDuo 只接受不嵌入凭据的代理端点，将模式和地址保存在本地偏好中，不实现代理认证。包内 chii 前端和 chobitsu 后端从本地提供，无需 CDN 或 Node 进程；检查时产生的页面、source map/资源请求及普通网站连接仍遵循页面/引擎的安全和网络规则。

已入库的 Safari 图集是经过明确审查的画布衍生图：只显示受控本地夹具与模拟器 UI，已裁掉 Device Hub 设备列表和桌面控件。索引排除原始浏览/环境记录及标签 UUID。公开文件审查验证精确图片名称、尺寸，以及没有嵌入 EXIF/XMP/ICC 元数据，但不能替代视觉或权利审查。

可选 REST 控制服务向本机客户端提供当前 URL/导航、宿主设置和原生/页面遥测。独立端口与可选 Bearer 令牌保存于偏好中；令牌与 CDP 令牌一样明文保存在本机、界面遮蔽显示，并从普通诊断序列化中排除。启用状态不保存。Swagger UI 仅在内存中保存输入的鉴权信息，刷新或关闭后清除。文档资源离线提供，关闭外部规范校验。

原生截图请求直接向 REST/CDP 客户端返回网页视口或设备合成图片，不在服务端保存图片。设备捕获限定于本进程窗口内的手机画布，不截取其他应用。图片可能包含页面内容，分享前应审查。

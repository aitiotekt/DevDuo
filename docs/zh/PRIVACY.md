# 隐私

DevDuo 的标定接收器及诊断输出写入本地文件，目前没有独立的分析服务或托管遥测收集器。用户选择远程 URL 时，仍会通过系统浏览器引擎连接该网站；本工具不提供匿名浏览。

测量页记录视口/屏幕指标、safe area、所选标签、环境及当前 URL；接收器增加时间戳、不透明记录 ID 和连接源地址。桌面观察器包含滚动/视口、标题、主机名和页面衍生颜色。原生采集还可能记录模拟器标识、浏览标题/URL、截图、视频、辅助功能树、工具输出路径及源哈希。

原始记录应放在被忽略的 `captures/`、`measurements/` 或 `.local/`。`temp/` 下生成的诊断输出也可能包含私人元数据。Windows WebView2 profile 和独立安装应用的诊断使用当前用户本地应用数据目录；`DEVDUO_OUTPUT_DIR` 可改变桌面状态输出位置。删除证据或浏览器 profile 是用户主动的本地操作，项目尚无自动保留期限策略。

公开配置保留部分模拟器测量值、源文件相对引用和哈希，原始会话不进入 Git。分享前必须检查元数据及图片，发布经过脱敏的衍生物，同时保持原件字节不变。不得公开密钥、个人主机名、模拟器标识、私人页面内容或用户目录路径。

另见[参考数据](002-MEASUREMENT-CONTRACT.md)和[安全](SECURITY.md)。

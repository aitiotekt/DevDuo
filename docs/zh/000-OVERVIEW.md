# 项目概览

DevDuo 将真实桌面 WebView 放入模拟器衍生的 iPhone Duo 屏幕几何，帮助 Web 开发者交互调试。Safari 模式复现测得的组件位置和视口变化，沉浸模式移除浏览器外壳并使用完整逻辑场景。

当前参考集覆盖折叠/展开 × 四个机身角度，含初始/滚动 Safari 状态及展开单/多标签页变体。这些是模拟器观测，不是物理设备尺寸保证或完整 Safari 实现。部分展开时的铰链/透视模型尚不可用。

从 [README](README.md) 开始，然后阅读[开发工具链](010-DEVELOPMENT.md)、[架构](001-ARCHITECTURE.md)和[测量约定](002-MEASUREMENT-CONTRACT.md)。新观测使用[标定流程](003-CALIBRATION-WORKFLOW.md)，完成与待完成的验证分列在[验证记录](008-VALIDATION.md)。

公开检出不需要原始证据即可运行。重新提取及完整截图/源框验证需要另外提供本地原件，详见[参考数据](007-REFERENCE-DATA.md)、[Windows 交接](009-WINDOWS-HANDOFF.md)及[宿主 UI 路线图](100-ROADMAP.md)。

## 先前更名与发布前整理

DevDuo 更名时已通过公开文件审查和 Python 标准库检查，包括并发持久化、非法输入拒绝、PNG 往返/差分、显式排除、尺寸不匹配拒绝及内外几何包含。SDK 10.0.401 下的 macOS Avalonia/Swift 构建和 Windows 交叉编译均为零警告、零错误，原生中间产物改为写入 obj。

从原始本地证据重新提取设备几何和八场景/24 状态，与公开配置语义完全一致。只含当时 69 个公开候选文件、不含 captures/measurements 的副本通过了检查和 macOS 构建。缺失私有提取输入会给出明确错误，不会捏造参考。

更名后的 DevDuo.app 已真实启动，通过辅助功能和窗口截图检查菜单/标题。Save state 测得折叠 Safari 382×580、折叠沉浸 466×678、展开 Fit 单标签 951×589、多标签 951×543，验证了命名后的 Swift 通道、JS、配置及源码检出输出。独立安装的诊断回退位置只作过代码检查，未单独运行验证。GitHub Actions 在实际推送运行前不声称通过。

## 已有交互基准

macOS 27 WKWebView 曾使用实际窗口、原生辅助功能、状态文件和独立 Device Hub 参考检查，历史原件本地保留，不进入 Git。

- 折叠/展开沉浸视口符合逻辑屏幕，内外路径独立，已观察非对称旋转圆角。
- 90° 非对称场景暴露了重复 Y 翻转，现已移除；对称纵向图形无法充分暴露该问题。
- 机身选择对应八个真实场景；Closed 180° 是顺时针序列保留的横向，不推广到所有旋转历史。
- 已检查 24 个 Safari 初始/滚动及单/多标签参考状态，macOS Fit 保持 CSS 视口。
- 展开选中标签使用包含关闭区域的完整 title-container，四个角度都对照了原始 native frame，文案统一字号居中。
- 折叠模式真实绘制地址栏下方普通流内容，并用遮挡 inset 保留较小 viewport；沉浸模式清空 inset。WK 快照不含全部呈现延伸，必须检查实际窗口。

窗口原始观察是 JPEG，PNG 转换必须标为衍生物。framebuffer 比较使用原始无损模拟器 PNG。差分统计只描述具体图对，不是硬件保真度评分。

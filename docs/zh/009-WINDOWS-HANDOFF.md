# Windows 交接

Windows 通过 Avalonia 使用固定版本的 WebKit Windows Port，macOS 保留系统 WKWebView。Safari 外壳和沉浸式 App WebView 均遵守[实测场景约束](005-SAFARI-SCENES.md)。本文统一记录当前 Windows 验收及回归范围；[WebKit 实现](014-WINDOWS-WEBKIT.md)、[发布交付](013-RELEASE.md)和[平台差异](015-PLATFORM-PARITY.md)分别维护。

0.1.3 源码构建在 0.1.2 的同帧延伸及保留式合成基础上，增加 fixed 图层裁剪和按区域独立的 Safari 材质取色。原页面底带染色及 fixed 可见性已有针对性复验。持续操作响应、完整弹窗覆盖、macOS 共享服务恢复和打包交付仍待验收。

## 0.1.4 发布配置

0.1.3 已发布引擎包含当前补丁，却关闭了异步滚动和原生触摸，因此该发布产物没有使用下文验收的路径。从 0.1.4 起默认构建启用两项能力；运行时暂存、归档复用、下载／缓存消费和最终应用归档会拒绝缺少能力或发布元数据不匹配的运行时。

本地已不带实验开关完成默认构建。加载其 DLL 确认触摸、滚动帧和帧表面 API 均为 v1，18 项原生滚动层断言通过。发布工具测试覆盖能力缺失／关闭、构建选项关闭和包身份错误。下文页面呈现证据为继承记录，GitHub 生成的 0.1.4 应用发布后仍需做打包产物冒烟检查。

## 继承的 0.1.3 本地检查

实验 Windows 运行时及 v6 合成器在 **120 DPI、Fit** 下通过 **47 项呈现稳定性检查**（`20261105T091316271Z`）。Closed 竖屏页脚由原生触摸和滚轮触发 CSS 过渡进出，另用 `requestAnimationFrame` 脚本直接更新 `transform`。在 **54 个触摸帧、67 个滚轮帧和 69 个脚本变换 WGC 帧**中，真实视口内可见红色按钮，所查底部延伸点均未采到红色。真实页脚几何和视口宽度保持，带 forwards fill 的变换结束后确认到稳定蓝色边缘。

深色外观下，底部正文绘制变色而侧栏局部背景保持稳定，实际窗口的 **74 个右侧竖屏帧和 77 个左侧横屏 WGC 帧**中，后退、书签和标签组按钮像素保持稳定。反复收起和展开后仍可原生点击保留的书签按钮。帧观察覆盖通用夹具，原网站及显示扫描输出节奏另行验收。

同一补丁运行时在 120 DPI 下通过 **336 项同帧延伸检查**（`20261105T091427386Z`）、**30 项外壳过渡检查**（`20261105T091511137Z`）和 **42 项上游 fixed 取色对照**（`20261105T091524392Z`），覆盖 Closed、Open 90°／270° 几何、来源及窗口像素、两种传输路径和图案底层夹具。

固定图层调查区分了两处故障。WC 提交滚动位置时重复应用锚点偏移，边缘取色则因透明全视口命中层绕过了实际绘制采样带的连续覆盖验证。独立轮询仍显示白色时，完整窗口像素与逐帧提交的填色已能区分这两类故障。回归夹具保留不同锚点的固定标记、横跨整边的渐变及定位父层内能够延伸的普通正文。上游 fixed 取色检查继续区分首次绘制已有卡片与先确认遮罩再显示卡片的情形。

前后两版引擎的 `test-windows-fixed-overlay` 全量检查都停在第一个绝对定位边缘加载用例。原生材质样本为 RGB 254、254、254，实际材质色为 RGB 251、252、253。红通道与白色相差四，夹具允许误差为三。独立上游 fixed 取色套件直接验收了原生对话框遮罩和两种遮罩打开顺序。

页面自带的外侧遮罩背景在 120 DPI、Fit 下通过同一文档的 **41 项检查**（`20261105T141508970Z`）。无绘制的全视口覆盖层不会挡住模态取色。有色不透明底板得到 RGB 15、20、25，移除底板后保留叠在文档根上的两次半透明贡献。前景绘制进入采样带、外侧块隐藏或覆盖不全、被遮挡、页面裁剪、颜色不一致或所属容器不同，均不会授权灰色填充。两枚固定标记在 58 个换向帧中保持可见，底带无红色提交或像素。此前的 114 项上游 fixed 取色和 336 项同帧延伸检查沿用原有证据。

原页面在 120 DPI、Fit 下，**371 个稳定 WGC 帧**均同时显示白色卡片和灰色底带，对应的 **425 次页面提交**均以 RGB 25、25、25 填充底带。在同一文档关闭弹窗后执行 24 次原生触控滑动，观测到 21 次换向，覆盖 382 × 580 和 382 × 598 两种视口。活动区间的 **895 个 WGC 帧和 1,028 次页面提交**均无底带红像素或红色填充，遮罩灰色已释放，采样的固定控件始终可见。私有证据位于 `captures/desktop-validation/windows-live-edge/`。

iOS 27.1 iPhone Duo 模拟器的 Safari 在 382 × 580 下也呈现首次白色与分步显示黑色的差异，卡片底边为 579.986 CSS px。macOS 27.0.1 系统 WKWebView 探针在首次直接加载时观察到白色底部延伸图层，在启用视图级自动填充的分步显示中观察到黑色图层。ScreenCaptureKit 未获权限，因此 macOS 结果记录图层状态，Safari 结果来自实际模拟器显示像素。证据见 `captures/desktop-validation/macos-dimming/20261105T094102Z`。

重建的实验运行时在 **120 DPI 通过 272 项触摸检查**（`20261105T061318817Z`）。GPU／CPU 路径覆盖可信事件、取消、touch-action、overflow 锁定和嵌套滚动。触摸拖动不产生 DOM wheel。页面主线程阻塞 2.4 秒期间，三个独立 GPU 帧保留源绘制并推进根滚动，阻塞结束后 DOM 在 21.37 ms 内收敛。Closed 0°、Open 90°／270° 覆盖 1:1 和 Fit。两项 1:1 Open 检查覆盖完整源帧和实际窗口的可见裁剪区。Fit 设备完整可见。

此前 **120 DPI 的 245 项复验**（`20261105T032637186Z`）验证了源栅格／HWND 取整修复，包括 582×847 来源与 582×848 输出不同时仍无丢帧；该批次早于最终接触时间及重复移动修正。深层过度绘制夹具的 **38 项输入／性能检查**（`20261105T032111393Z`）记录 GPU 触摸 rAF p95 为 18ms、CPU 为 106ms；这是 JavaScript 节奏，不是 DWM FPS 或任意网站延迟。私有静态副本在参照与实验运行时都较流畅，因此没有复现原始动态页面迟滞，也不能证明原网站改善。

三个触发式网页进程 CPU 快照中，两次捕获到完整 AX 树遍历（`20261104T212839448Z-pipeline-profile`）。这定位到正在运行的昂贵路径，不等于统计 CPU 排名。宿主已不再为每个通知同步重建整树；页面帧携带自身延伸，避免遇到独立提交的宿主填色，完整材质角色配方也与几何一起插值。

**剩余发布阻塞：** 原始动态页面的材质／流畅性及更广的异步输入／生命周期验收仍未完成。已验收参照运行时使用主线程滚动和 DOM 触摸仿真；独立实验仅在上述范围证明了原生单触点规则及独立滚轮／触摸呈现。高速惯性和动态结构变化还需验收；GPU 生产者仍保留 GL 完成等待。共享逻辑的 macOS 服务恢复、安装包、多适配器兼容及设备丢失注入仍未验证，不能以本地夹具节奏或 DOM 几何替代这些门槛。

未修改的 fixed 遮罩、无障碍及服务恢复行为沿用对应版本证据。表中上游规则、过渡、普通页面布局及材质缓动检查使用此前同帧栅格运行时，不算共享表面运行时重跑。早期方向、时钟顺序及静态玻璃失败证据均保留。成功源码构建为后续 checkout 启动选择运行时，已运行实例继续使用原二进制。

- 匹配依赖／应用包交付及再分发审查仍待完成。完整运行时验收保持 false，不代表每次修改都要重启整轮审计。

## Windows 里程碑与增量回归

默认只在**当前可用的单一实际 DPI** 检查受影响功能。不能因为改了 Windows 文件就切换系统缩放、要求另接显示器、重建 WebKit 或跑全部原生 recipe；只有引擎输入变化才重建引擎，日常检查保留缓存。

| 修改范围 | 选择的验证 |
| --- | --- |
| 文档 | `just docs-check`、`just build-docs`、公开信息审计及 diff 审查，不构建或运行原生程序。 |
| 共享状态或本地化 | 对应 `just test-core`／`just test-localization`；运行时／UI 行为改变时补平台构建和限定原生观察。 |
| 无障碍 | `just test-windows-accessibility`；发现入口、焦点或朗读语义变化时补短时讲述人观察。 |
| IME、select 或 JavaScript 对话框 | 对应 `just test-windows-ime`、`just test-windows-popups` 或 `just test-windows-page-dialogs`。 |
| 材质、绘制或内容延伸 | 对应呈现／inset／固定遮罩检查和实际窗口；栅格边界变化时在同一 DPI 加分数 Fit。 |
| 触摸圆点呈现 | `just test-windows-touch-pointer`、相关交互检查及实际窗口移动观察；显隐标志不能替代旧位置像素检查。 |
| 启动／导航或开发服务 | 对应导航延迟、开发工具或调试检查。 |
| 共享视口／遮罩／旋转或广泛引擎集成 | Core／构建、单 DPI 的 `just test-windows` 及相关原生检查；仅布局／inset 语义变化时加普通页面几何比较。 |
| 依赖选择或打包 | 发布／构建／打包检查及单 DPI 的包启动／运行时加载观察，沿用未变引擎的行为证据。 |

表格用于选择，不能逐行全部执行。`just verify` 是可移植检查／构建集成，不包装 Windows 原生验收。修复后重跑受影响检查，只有另一受影响边界、无法解释的失败或明确扩大验收请求才增加覆盖。

额外 DPI 仅针对缩放换算、弹窗／caret／命中的物理坐标、像素取整／裁剪、跨屏资源生命周期变化或缩放专属故障。先说明原因，再选最小有效对比；只有分数 DPI 相关才补 150%。Fit 与 DPI 不同。环境不可用时记录缺口，不反复要求用户调整桌面。

无障碍 recipe 默认不跨屏；`DEVDUO_TEST_MONITOR_TRANSITIONS=1` 显式开启该用例，并要求不同实际缩放的显示器。`DEVDUO_TEST_SCREEN_SCALE` 可选一个匹配且唯一的真实显示器，两者均不修改系统缩放，日常不设置即可。`DEVDUO_TEST_FOREGROUND_GATE=1` 等待原生 Start 按钮后才注入输入。`DEVDUO_TEST_IME_PROFILE=microsoft-pinyin` 仅为测试进程选择已启用的输入法，结束后恢复原 profile，不注册系统键盘。

`just test-windows-modal-sequence` 检查嵌套弹窗边缘、颜色标量稳定、保留式合成和开发者服务开关。`DEVDUO_TEST_MODAL_BODY_ANGLE=0`、`90` 或 `270` 将诊断限定为 Closed 0°、Open 90° 或 Open 270°；不设置则执行受影响的三个姿态。`just test-windows-developer-restore` 使用隔离偏好和八次真实应用启动，验证监听冲突隔离、损坏配置阻止及下次启动恢复。

选择实验性原生触摸运行时后，`DEVDUO_TEST_TOUCH_LIFECYCLE_ONLY=1` 让 `just test-windows-native-touch` 检查触点结束、惯性停止及动态滚动约束。`DEVDUO_TEST_TOUCH_TRACKING_ONLY=1` 检查后备缩放大于一且有小数时的单物理像素移动与反向。`DEVDUO_TEST_TOUCH_SEAM_ONLY=1` 检查源帧与实际窗口像素，覆盖快速视口切换和停稳后的分数 Fit。可同时设置 `DEVDUO_TEST_TOUCH_SEAM_STATIC_ONLY=1`，只跑停稳用例。默认执行手势规则、绘制路径和繁忙页面姿态批次。各项检查使用独立测试 profile。

## 原生验收清单

按变化选择相关项，不是每次编辑必须执行的全量流程。

1. 独立记录真实加载的运行时、DPI、Fit 和原生框，不把请求设置当观测结果；验证实际方向，保留 Closed 180° 旋转历史限定。
2. 呈现变化保持真实视口、fixed／sticky 框、视口单位和滚动范围；区分四向有效正文、文档外背景与固定颜色延伸。
3. 同时检查实际窗口像素／交互及 DOM／遥测。有内容的树、快照、GPU 提交或源栅格不能替代实际窗口证据。
4. 同时使用无插入标记的静态页和动画；覆盖相关滚动／文档末端／缩放／导航变化，不通过插入 fixed 元素、强制重绘循环或伪造 DOM 尺寸绕过问题。
5. 输入路径变化时检查焦点、键盘／IME、旋转菜单／caret／命中及公开应用树；提交了一个中文字符不等于预编辑通过。
6. 验证导航／销毁拒绝旧回调和迟到 HWND／DPI 操作；纯呈现设置不能导航或重置文档。

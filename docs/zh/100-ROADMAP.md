# 宿主 UI 路线图

桌面宿主是围绕实测设备预览的标定工作台：真实地址栏、分组设置侧栏和状态栏，基于 Avalonia 12 并使用 SukiUI 主题。宿主改进必须保持实测设备 viewport 与 Safari 外壳不变。持久化的英/简中本地化覆盖全部宿主控件。

## 已实现的宿主行为

- **浏览器控制。** 宿主地址栏绑定当前原生 WebView：显示重定向后的提交地址、页面标题、加载进度、带重试的失败状态，支持 Enter 导航、后退/前进、重新加载/停止及内联校验。保留 query 与 fragment。测量标签只附加到本地标定页，任意开发 URL 原样打开。
- **共享导航状态。** WKWebView 与 Windows WebKit 上报同一 `NavigationState`，已销毁容器的过期回调会被忽略。外框、缩放、语言、主题、标签栏和材质等呈现变化保留已加载页面；机身旋转更新当前原生视图，设备形态和容器模式则会在当前页面重新创建原生视图，并在状态栏说明。见[架构](001-ARCHITECTURE.md)。
- **分组设置与持久化。** 开发工具置于顶部，每个窗口默认折叠，之后是设备、容器、预览和外观分组，材质调节和诊断可折叠。不适用的选项禁用并给出说明。除机身角度和开发工具展开状态外的宿主设置保存在 `preferences.json`；**重置设置**恢复 Safari · 折叠 · 机身 0° · 1:1。
- **视觉与交互。** SukiUI 控件主题加 DevDuo token，统一字体、间距、图标、focus/hover/pressed/disabled 状态及明暗主题。设备预览为视觉重点；详细指标移入诊断面板，状态栏只显示可操作状态。适应预览跟随可用预览区域。
- **键盘与无障碍。** 聚焦地址栏、重新加载、停止、历史、保存状态和设置面板的快捷键（macOS 同时提供原生**导航**菜单）；本地化的无障碍名称、禁用项说明、带快捷键的提示和状态 live region。

当前平台能力与验收由[平台能力](015-PLATFORM-PARITY.md)维护，后续变化仅复验受影响原生行为。

## 验收边界

宿主地址栏与模拟设备内部的 Safari 地址表面职责不同。后者属于标定场景，应保留测量框、悬浮行为和页面衍生外观。多标签开关只表示外壳变体，不隐含完整标签管理器。

保留两种容器、八个机身/折叠映射、展开单/多标签、滚动转换、独立内外路径和实际 CSS viewport。宿主面板可以改变可用显示空间，但不能悄然改变逻辑设备尺寸，修改前后用相同设置核对状态。不将普通 Avalonia 控件覆盖在原生浏览器子视图之上。

Safari 组件、系统玻璃、硬件模拟和设备几何是分别需要证据的工作，不通过通用视觉重设计替换测量框或声称光学等价。
